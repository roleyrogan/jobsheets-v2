# JobSheets

A job application tracker for students and job seekers, built with React, TypeScript and Supabase.

A rewrite is in progress on the `rewrite` branch — see [docs/PLAN.md](docs/PLAN.md).

## Run locally

```bash
npm install
cp .env.example .env   # then fill in VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
npm run dev
```
